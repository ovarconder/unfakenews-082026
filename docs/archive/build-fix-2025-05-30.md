# Build Fix — 30 May 2025

## ปัญหา: Build Failed — Barrel Optimization Bug ใน Next.js

### Error
```
Module parse failed: Identifier 'Globe' has already been declared (6:144)
import { Save, Shield, Globe, ... Globe, Globe, Link } from "__barrel_optimize__?names=...,Globe,...!=!lucide-react";
```

### สาเหตุ
Next.js 14 SWC barrel optimization ร่วมกับ `lucide-react` มี bug ที่ทำให้ชื่อ `Globe` ถูก inject ซ้ำ 3 ครั้งใน transformed import แม้ source code จะ import `Globe` แค่ครั้งเดียว

### การแก้ไข

#### 1. `app/admin/settings/page.tsx`
- **ลบการ import `lucide-react` ทั้งหมด** (Save, Shield, Globe, Database, Check, AlertCircle, Palette, Image, FileText, Lock, Eye, EyeOff, Twitter, Facebook, Instagram, Youtube, Link)
- **สร้าง `SvgIcon` component** แทนที่ โดยใช้ inline SVG paths ทั้ง 15 icons:
  - `save`, `shield`, `check`, `alert`, `palette`, `image`, `filetext`, `lock`, `eye`, `eyeoff`, `facebook`, `twitter`, `instagram`, `youtube`, `link`, `globe`, `database`
- ปรับโครงสร้าง component helpers:
  - `Section` — reusable card wrapper
  - `Banner` — success/error notification
  - `Input`, `TA` (textarea), `ImgField`, `CF` (color field), `TR` (toggle row), `Badge`

#### 2. `lib/locales.ts`
- เพิ่ม `ALL_LOCALES` จาก `["en"]` → 15 languages (en, th, zh, ja, fr, ko, de, es, pt, ru, ar, hi, it, vi, ms)
- เพิ่ม `TIER1_LOCALES` ให้ครบ 15 ภาษา
- เพิ่ม `LOCALE_NAMES` ให้ครบทุกภาษา (native + english name)

#### 3. `components/articles/article-detail.tsx`
- **Syntax fix**: `.then()` chain ที่ขาด `fetch()` ถูก comment ออก (client-side translation ยังไม่ implement)
- **ฟังก์ชันหาย**: `getTagName` ถูกเปลี่ยนเป็นแสดง `{tag}` โดยตรง
- **Locale compare**: เปลี่ยน `locale === "th"` → `locale !== "en"` เพื่อให้สอดคล้องกับ 15 languages

#### 4. `components/analytics/cookie-consent.tsx`
- ปรับ `consentTranslations` จาก 15 ภาษา → เหลือเฉพาะ `en` (ตาม requirement เดิม)
