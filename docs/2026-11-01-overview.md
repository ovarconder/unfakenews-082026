## 2. Tech stack

Next.js 14 (App Router) · React 18 · TypeScript · Tailwind CSS · Supabase (Postgres + Auth + Storage) · Tiptap editor · AI แปลภาษา (Gemini)

## 4. แนวคิดหลักของข้อมูล

- **`articles`** เก็บต้นฉบับ (`original_title / original_excerpt / original_content`) ในภาษาตาม **`source_locale`**
- **`translations`** เก็บคำแปลภาษาอื่น 1 แถวต่อ (article, locale)
- ภาษา "เผยแพร่จริง": ต้นฉบับ = `articles.status = 'published'`, คำแปล = `translation_status = 'complete'`
- รายละเอียดการแปล: [translation-and-source-locale](2026-11-03-translation-and-source-locale.md)

## 5. สิทธิ์ผู้ใช้

Supabase Auth (email + password, สร้างผู้ใช้จากหลังบ้านเท่านั้น) + ตาราง `profiles.role`: `writer` / `editor` / `admin`
ผู้อ่านทั่วไปไม่ต้อง login
